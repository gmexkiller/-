# 胡拉拉《斜面》课堂互动平台

## 教师电脑 + 学生平板局域网版

局域网版不使用 CloudBase，不需要 VPN，也不会产生云服务费用。教师电脑和学生平板只需连接同一个 Wi-Fi。

1. 双击 `启动局域网课堂.cmd`。
2. 首次运行会自动制作可独立运行的课堂包，完成后自动打开教师页面。
3. 如 Windows 防火墙提示，允许 `node.exe` 通过“专用网络”。
4. 创建课堂并展示二维码，学生平板扫码加入。
5. 上课期间保持启动窗口开启；关闭窗口即可停止服务器。

“上山路线设计”采用 3D 山地工程沙盘：学生先在“修路”模式点按山体逐段铺路，再用“调整”模式拖动节点，最后切换到“观察”旋转、缩放山体并试跑货车。教师大屏可打开任一作品进行 3D 讲评，也可同步比较两组方案。

平板建议使用横屏或竖屏，Chrome、Edge、Safari 等支持 WebGL 的现代浏览器均可使用；若设备不支持 3D，会自动显示俯视路线图。

课堂记录保存在 `output/斜面课堂局域网版/data/local-classrooms.json`。重新制作局域网版时会保留已有记录。

如果平板无法打开，请确认设备处于同一 Wi-Fi，且路由器没有开启“客户端隔离”或“AP 隔离”。

## 开发与构建

- `npm run dev`：开发模式。
- `npm run build`：构建 CloudBase 函数包。
- `npm run build:lan`：构建带 Node.js 运行时的 Windows 局域网课堂包。
